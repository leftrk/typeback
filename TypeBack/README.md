# TypeBack

macOS 输入法自动回切工具。打完中文停顿一段时间后，自动切回英文输入法。

## 功能

- **自动回切**：中文输入停止 2 秒开始倒计时，超时后自动切到英文
- **ESC 快切**：中文模式下按 ESC 立即切回英文，按键事件穿透不影响前台应用
- **圆形指示器**：浮动在屏幕上，显示当前输入法状态和倒计时进度弧，可拖动定位
- **候选框感知**：输入法候选框打开时暂停倒计时
- **系统唤醒**：电脑唤醒后自动切到英文
- **禁用 Caps Lock**：可选，仅保留切换输入法功能，禁用长按锁定大写

## 构建与运行

```bash
cd TypeBack

# 构建 + 运行
./run.sh

# 仅构建
swift build

# 直接运行已构建产物
.build/debug/TypeBack
```

## 权限

首次运行需要授权 **辅助功能权限**：

系统设置 → 隐私与安全性 → 辅助功能 → 添加 TypeBack（或终端）

## 配置

单击指示器切换输入法，双击打开设置。也可点击菜单栏图标 → 设置。

| 设置项 | 选项 |
|--------|------|
| 超时时间 | 30s / 60s / 120s |
| 禁用 Caps Lock | 开/关 |
| 开机自启动 | 开/关 |

## 项目结构

```
├── UI/            # 浮动指示器、菜单栏、设置窗口
└── Utils/         # TIS API、权限、日志
```

详细架构见 `docs/v1/prd.md`。

## 技术栈

- Swift 5.10，macOS 14.0+
- SwiftUI + AppKit（NSPanel 浮动窗口）
- CGEventTap 键盘监听，TIS API 输入法切换
