> 修订日期：2026-05-19

## 1. 产品概述

TypeBack 是一款 macOS 输入法状态可视化与自动回切工具，专为中英文混合输入的开发者设计。

**核心价值**：

1. **状态时刻可见** — 用浮动指示器解决"看不到当前输入法状态"的问题
2. **显式快捷键一键回英文** — 用户自定义组合键，确定性强
3. **可选的自动回切** — 中文停顿后自动切回英文（兜底，默认开启）
4. **Caps Lock 可设为仅切换输入法** — 默认保持系统行为；打开开关后禁用长按锁定大写

目标用户：vim/终端用户，日常中英文混合输入者。

## 2. 核心行为

### 2.1 状态机

```
英文 [EN]
    │
    │ 用户切到中文输入法（任意触发：系统快捷键 / Caps Lock / 指示器单击）
    ▼
中文·空闲 [CN]
    │
    │ 有键盘活动
    ▼
中文·输入中 [CN]
    │
    │ 停止键盘活动 2 秒（typingEndDelay）
    ▼
中文·倒计时 [CN + 进度弧]
    │
    │ 倒计时归零
    ▼
英文 [EN]
```

**关键澄清**（修正 v1 口径不一致）：

- `中文·空闲` 和 `中文·倒计时` 是**两个独立状态**。从输入中过渡到空闲后，**立即进入倒计时**，倒计时归零才切回英文。
- 状态机内部回调命名：`.typing` / `.idle` / `.countdown` / `.timeout`。

### 2.2 行为规则

| 场景 | 行为 |
|------|------|
| 切到中文输入法 | 进入「中文·空闲」，立即开始倒计时（如果自动回切开启） |
| 中文模式下有键盘活动 | 重置倒计时，进入「输入中」 |
| 停止输入超过 2 秒 | 进入「空闲」，立刻进入倒计时 |
| 倒计时归零 | 自动切回英文 |
| 按下「回英文快捷键」（任意模式） | 立即切回英文，事件**消费**不穿透 |
| 候选框打开时 | 暂停倒计时，候选框关闭后重新开始 |
| 系统唤醒 | 自动切回英文 |
| 全屏应用激活 | 指示器隐藏，状态机正常运行 |
| 自动回切关闭 | 倒计时不启动，仅靠快捷键切回 |

**注意**：v1 写的 ESC 切回行为已**移除**。回英文统一走「自定义快捷键」机制（默认 ⌃Space）。

### 2.3 倒计时配置

| 项目 | 值 |
|------|------|
| 停顿判定（typingEndDelay） | 固定 2 秒 |
| 倒计时总时长 | 30 / 60 / 120 秒，默认 60 |
| 自动回切总开关 | 默认开启，可在设置中关闭 |

## 3. 浮动指示器

### 3.1 造型

圆形，52×52 外框，36px 表盘直径。

| 状态 | 表盘 | 字形 | 字色 | 光晕 |
|------|------|------|------|------|
| 英文 | 近白（0.97 白，90% 不透明） | EN | 黑色 45% 不透明 | 冷调浅蓝白光晕 |
| 中文·空闲 | 近黑（0.12 白，90% 不透明） | CN | 白色 80% 不透明 | 暖调橘红光晕 |
| 中文·输入中 | 近黑 | CN | 白色 80% 不透明 | 暖调橘红光晕（更亮） |
| 中文·倒计时 | 近黑 | CN | 白色 80% 不透明 | 暖调橘红光晕（随进度衰减） |

字体：SF Rounded，11px medium，tracking 0.3。

投影：`rgba(0,0,0,0.15)` blur 6 y 2，单层。

### 3.2 外发光光晕（v2 新增）

圆形外圈一层柔和光晕。技术上用 SwiftUI 的 `.shadow(color:radius:)` 或多层 blur 实现，**简单、低成本**。

- 半径：6–10px
- 不透明度：0.4–0.6（随状态）
- 颜色：跟随状态主色（中/英不同）
- 静态长亮，不脉动（除非倒计时最后 5 秒）

### 3.3 状态切换水波动画（v2 新增）

当输入法状态切换时（EN ⇄ CN），从圆心向外扩散一圈水波。

| 参数 | 值 |
|------|------|
| 时长 | 0.4–0.6s |
| 起始半径 | 表盘半径（18px） |
| 终止半径 | 外框 1.5 倍（~78px） |
| 描边宽度 | 起始 2px → 终止 0px |
| 不透明度 | 起始 0.8 → 终止 0 |
| 颜色 | 目标状态的主色 |

实现：`Circle().stroke(...)` + `.scaleEffect` 动画 + `withAnimation(.easeOut)`。

### 3.4 进度弧

倒计时显示，顺时针消退（`progress = 剩余秒 / 总时长`）。白色，1.6px，圆头。

**仅有的动画**：倒计时最后 5 秒，弧线 opacity 在 0.5↔1.0 之间脉冲（0.9s 周期）。状态切换用 opacity 过渡（0.25–0.3s ease-in-out）。尊重 `accessibilityReduceMotion`，开启时禁用脉冲与水波动画。

### 3.5 全屏行为（v2 修订）

全屏应用激活时，**指示器隐藏**。

实现方案：移除 `.fullScreenAuxiliary` collectionBehavior；或监听 `NSWorkspace.activeSpaceDidChange` + 检测当前 Space 是否含全屏窗口，主动 `orderOut`。

状态机和键盘监听**不受影响**，继续后台运行。退出全屏后指示器恢复显示。

### 3.6 交互

| 操作 | 行为 |
|------|------|
| 单击 | 切换输入法（EN ⇄ CN） |
| 双击 | 打开设置 |
| 拖动 | 移动位置（自动保存到 UserDefaults） |

## 4. 自定义快捷键（v2 新增）

### 4.1 默认值

`⌃Space`（Ctrl + Space）。沿用 v1 实际代码的硬编码行为，新用户不需要重新配置。

### 4.2 行为

- 在**任何输入法状态**下按下，立即切到英文
- 事件被**消费**，不穿透给前台应用（与 Ctrl+Space 的系统输入法切换冲突时由 TypeBack 接管）
- 已经是英文时按下：无副作用

### 4.3 录制交互

设置面板的快捷键卡片：

```
┌────────────────────────────────────┐
│  快捷键                             │
│                                    │
│  立即回英文      [⌃Space]  [录制]  │
└────────────────────────────────────┘
```

录制流程：

1. 用户点击「录制」按钮 → 按钮变为「请按下组合键…」状态
2. 监听下一次完整的键盘组合（修饰键 + 非修饰键）
3. 捕获后立即写入 AppState，按钮恢复正常态显示新组合
4. 按 ESC 取消录制，保留原配置

### 4.4 冲突处理

- 若用户录制的组合与系统快捷键冲突，TypeBack **优先消费**（已有 CGEventTap 权限可做到）
- 录制纯修饰键（如单独 ⇧）禁止，提示"请包含至少一个非修饰键"

### 4.5 持久化

`AppState` 新增字段：

```swift
var shortcutKeyCode: UInt16        // 默认 kVK_Space (49)
var shortcutModifiers: UInt        // 默认 NSEvent.ModifierFlags.control.rawValue
```

## 6. 设置窗口（v2 重做）

### 6.1 设计原则

- **与指示器统一风格**：圆角、SF Rounded 字体、配色呼应
- **去 Divider，改卡片化分组**：每组功能一张毛玻璃卡片（`.regularMaterial`），用留白而非分割线区分
- **顶部 hero 区放活的迷你指示器**：实时同步当前输入法状态，让用户一眼明白"这是同一个软件"
- **微动画**：Toggle/Picker 状态变化加 spring 动画

### 6.2 布局草案

```
┌────────────────────────────────────┐
│                                    │
│         ●  (活的迷你指示器 36×36)   │
│        TypeBack                    │
│        输入法状态与自动回切          │
│                                    │
│  ┌──────────────────────────────┐ │
│  │ 自动回切                      │ │
│  │   启用自动回切      [开关]    │ │
│  │   停止输入后        [60s ⌄]   │ │
│  └──────────────────────────────┘ │
│                                    │
│  ┌──────────────────────────────┐ │
│  │ 快捷键                        │ │
│  │   立即回英文   [⌃Space][录制] │ │
│  └──────────────────────────────┘ │
│                                    │
│  ┌──────────────────────────────┐ │
│  │ Caps Lock                     │ │
│  │   仅切换输入法      [开关]    │ │
│  │   开启后长按不再锁定大写       │ │
│  └──────────────────────────────┘ │

│  ┌──────────────────────────────┐ │
│  │ 开机自启动          [开关]    │ │
│  └──────────────────────────────┘ │
│                                    │
└────────────────────────────────────┘
   宽度 400px，自适应高度
```

### 6.3 设置项

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 启用自动回切 | Toggle | 开 | 关闭后只靠快捷键，倒计时不启动 |
| 停止输入后 | Picker | 60 秒 | 30 / 60 / 120 秒可选，仅在自动回切开启时有效 |
| 立即回英文（快捷键） | 录制器 | ⌃Space | 见第 4 章 |
| Caps Lock 仅切换输入法 | Toggle | 关 | 默认保持系统行为；打开后长按不再锁定大写，Caps Lock 仅用来切换输入法 |
| 开机自启动 | Toggle | 关 | 使用 SMAppService |

**措辞注意**：v1 的「禁用 Caps Lock 大写锁定」改为正向描述「Caps Lock 仅切换输入法」，避免双重否定。底层 `AppState.disableCapsLock` 字段建议重命名为 `capsLockSwitchOnly`（保持反向兼容由迁移逻辑处理）。

## 7. 权限引导

首次启动无辅助功能权限时，弹 `NSAlert`：两个按钮（打开系统设置 / 退出），点击「打开系统设置」后应用退出。运行中权限被撤销时，菜单栏图标加红色徽标提示，主动弹同样的 Alert。

## 8. 技术规格

| 项目 | 选择 |
|------|------|
| 语言 | Swift 5.10 |
| UI 框架 | SwiftUI（设置/指示器内容）+ AppKit（NSPanel 浮动窗口） |
| 最低支持 | macOS 14.0 (Sonoma) |
| 架构 | Menu Bar App（`LSUIElement = true`） |

| 功能 | 实现 |
|------|------|
| 输入法切换 | TIS API（`TISSelectInputSource`） |
| 输入法状态同步 | 0.5s 轮询（`Timer`） |
| 键盘监听 | `CGEventTap`（与快捷键监听共用） |
| 倒计时 | Swift Concurrency `Task`（无 RunLoop 依赖） |
| 候选框检测 | AX API |
| 开机自启动 | `SMAppService` |
| 系统唤醒监听 | `NSWorkspace.didWakeNotification` |
| 全屏检测 | `NSWorkspace.activeSpaceDidChange` + Space 全屏判断 |
| 快捷键录制 | 临时 local monitor `NSEvent.addLocalMonitorForEvents` |

**为何继续选 0.5s 轮询而非 `kTISNotifySelectedKeyboardInputSourceChanged`**：分布式通知在某些系统版本下延迟不稳，轮询实现简单且 CPU 开销可忽略。如未来需优化电量，可改为通知 + 轮询兜底。

## 10. 非目标（v2 新增）

明确**不做**以下事情，避免功能蔓延：

- 不按应用区分策略（vscode 和 terminal 行为一致）
- 不做使用统计/数据上报
- 不支持多语言 UI（只有简体中文）
- 不支持多套快捷键预设
- 不接管系统输入法切换的全局逻辑（仅在 TypeBack 自身职责范围内）
- 不做 Apple Silicon / Intel 差异化打包

---

## 11. 异常路径（v2 新增）

| 场景 | 处理 |
|------|------|
| TIS 切换失败（无中文输入法 / 无英文输入法） | 日志记录，菜单栏文字降级为「无可用输入法」 |
| CGEventTap 被系统禁用（如权限撤销） | 显示权限引导 Alert，菜单栏图标加红色徽标 |
| AX API 拿不到候选框信息 | 兜底为「无候选框」，倒计时正常运行 |
| 用户录制的快捷键被其他应用占用 | TypeBack CGEventTap 优先消费，不主动检测冲突 |
| 系统拒绝授权辅助功能 | 应用退出，下次启动重新引导 |
