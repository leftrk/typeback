# TypeBack 产品需求文档 (PRD) - v1 MVP

## 1. 产品概述

### 1.1 产品定位
TypeBack 是一款 macOS 输入法自动回切工具，专为 vim 用户和中文开发者设计。核心理念：**打完中文后，自动回到英文状态**。

### 1.2 目标用户
- vim 用户、终端用户
- 中文 + 英文输入法使用者

### 1.3 核心价值
解决「打完中文后忘记切回英文」的痛点。

---

## 2. 核心功能逻辑

### 2.1 状态流转

```
英文模式 [EN]
    ↓ 用户切换到中文
中文模式 [中] → 有键盘活动 → 重置倒计时
    ↓ 无键盘活动，倒计时开始
中文模式 [中|42s] → 倒计时归零 → 切回英文 [EN]
```

### 2.2 行为规则

| 场景 | 行为 |
|------|------|
| 切到中文输入法 | 开始倒计时 |
| 有键盘活动（中文模式下） | 重置倒计时 |
| 倒计时归零 | 自动切回英文 |
| 系统唤醒 | 自动切到英文 |
| 按下 ESC（中文模式下） | 立即切回英文，事件穿透给应用 |
| 按下 ESC（英文模式下） | 不拦截，事件正常传递 |

### 2.3 ESC 快捷键设计

全局监听 ESC 键，行为等同 vim 的 normal mode 回切：

- **幂等**：已经是英文时无任何操作，不会 toggle
- **穿透**：切换输入法后，ESC 事件照常传递给前台应用（关弹窗、取消操作等不受影响）
- **候选框优先**：中文输入法候选框打开时，ESC 由系统处理（关闭候选框），不额外切换输入法

### 2.4 默认配置

| 配置项 | 默认值 |
|--------|--------|
| 超时时间 | 60秒 |

## 3. 设计语言

### 3.1 设计原则

- **安静优先**：常驻屏幕的元素必须克制，英文状态下几乎隐入背景
- **一目了然**：余光一扫就能判断当前状态，不需要阅读文字
- **拒绝红绿灯**：不用红/绿表示中/英，避免"警告"心理暗示。用色温区分——暖色=中文（活跃），冷色=英文（安静）
- **真实光影**：用投影落地，不用 blur 发光。一个主投影 + 一个贴近投影，模拟真实光源

### 3.2 色彩系统

| 语义 | 色值 | 用途 |
|------|------|------|
| 表盘底色 | `rgb(23, 26, 31)` 92% 不透明 | 深石墨，沉稳不抢眼 |
| 英文字色 | `rgb(224, 230, 240)` 55% 不透明 | 冷灰白，低调退后 |
| 中文字色 | `rgb(245, 232, 209)` 88% 不透明 | 暖象牙，视觉主角 |
| 倒计时弧（起始） | `rgb(217, 168, 115)` | 琥珀色，时间充裕 |
| 倒计时弧（终末） | `rgb(138, 106, 68)` | 暗褐色，时间紧迫。从琥珀连续渐暗，不经过红色 |

## 4. 浮动指示器

### 4.1 造型：精密时计

圆形表盘，三层结构，从底到顶：

1. **表盘**：深石墨圆盘（直径 38px），顶部一条 0.8px 亮边模拟光源——唯一的拟物细节
2. **环轨 + 进度弧**：表盘内嵌一圈极淡环轨（6% 白色）。倒计时时，琥珀色弧线沿环轨消退，直观表达剩余时间
3. **中心字形**：状态文字居中。中文模式 "中"（16px medium），英文模式 "EN"（11px semibold），SF Rounded 字体

外框 46 × 46px。真实投影：主阴影 `rgba(0,0,0,0.45)` blur 10 y 3，贴近阴影 `rgba(0,0,0,0.20)` blur 2 y 1。

### 4.2 状态表现

| 状态 | 字形 | 字色 | 进度弧 |
|------|------|------|--------|
| 英文 | EN | 冷灰白 55% | 无 |
| 中文（输入中） | 中 | 暖象牙 100% | 无（键盘活跃时弧线隐藏） |
| 中文（倒计时） | 中 | 跟随弧色 | 琥珀弧，比例 = 剩余秒数/总时长，末段渐暗 |
| 中文（最后 5 秒） | 中 | 跟随弧色 | 弧线 opacity 脉冲 0.55↔1.0（周期 0.9s），仅此一处动画 |

### 4.3 位置

屏幕右侧三分之一、垂直居中。固定位置，v1 不支持拖动。

### 4.4 交互

| 交互 | 行为 |
|------|------|
| 单击 | 切换输入法 |
| 双击 | 打开设置 |

### 4.5 动画克制原则

- 无呼吸动画、无常驻闪烁
- 状态切换时字形用 opacity 过渡（0.2s ease-in-out），不用弹跳/缩放
- 唯一动画：倒计时最后 5 秒的弧线 opacity 脉冲，提醒即将切换。尊重 `accessibilityReduceMotion`，开启时禁用

## 5. 菜单栏

### 5.1 图标

静态几何图形，小圆点即可。不随状态变色（状态由浮动指示器表达，菜单栏只是入口）。

### 5.2 下拉菜单

```
┌─────────────────────┐
│ 当前: 中文 (42s)     │  ← 状态文字，不可点击
├─────────────────────┤
│ 立即切回英文         │
│ 设置...       ⌘,    │
├─────────────────────┤
│ 退出 TypeBack        │
└─────────────────────┘
```

---

## 6. 设置窗口

`⌘,` 或菜单栏「设置...」打开。单页，macOS 原生风格。

| 设置项 | 控件 | 选项 |
|--------|------|------|
| 超时时间 | 下拉 | 30s / 60s / 120s |
| 开机自启动 | 开关 | 默认关 |

窗口尺寸紧凑（约 360 × 200），无多余装饰。关闭窗口即保存。

---

## 7. 首次启动

单页权限引导：标题 + 一句话说明 + 两个按钮（打开系统设置 / 退出）。不做多步引导、不做教程。

## 8. 技术规格

| 项目 | 选择 |
|------|------|
| 语言 | Swift 6+ |
| UI 框架 | SwiftUI (设置界面) + AppKit (浮动窗口) |
| 最低支持 | macOS 14.0 (Sonoma) |
| 架构 | Menu Bar App (LSUIElement = true) |

### 核心技术实现

| 功能 | 实现方式 |
|------|----------|
| 输入法切换 | TIS API |
| 键盘事件监听 | CGEventTap |
| 系统唤醒监听 | NSWorkspace.didWakeNotification |
