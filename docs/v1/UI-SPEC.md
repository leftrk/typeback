# TypeBack UI-SPEC — 经典 macOS 风格

## 设计理念

抛弃自定义暗色面板，全面拥抱 macOS 原生视觉语言：
- **系统材质**：用 `.regularMaterial`（磨砂玻璃）替代固定深色背景，自动适配亮/暗模式
- **SF Symbols**：菜单栏使用系统符号图标
- **语义色彩**：用 `Color.primary / .secondary` 等系统语义色，让系统管理对比度和可访问性
- **克制投影**：macOS 标准窗口投影，不做夸张的多层阴影

## 1. 浮动指示器

### 1.1 材质与形状

| 属性 | 旧 | 新 |
|------|----|----|
| 背景 | `rgb(23,26,31)` 92% 固定深色 | `.regularMaterial` 磨砂玻璃 |
| 顶部亮边 | 0.8px 渐变描边 | 移除（材质自带深度感） |
| 投影 | 双层重阴影 | 单层 `shadow(radius:4, y:2)` 0.15 黑 |
| 外框 | 46×46 | 46×46（不变） |
| 表盘直径 | 38px | 38px（不变） |

### 1.2 色彩（适配材质背景）

| 状态 | 字色 | 说明 |
|------|------|------|
| 英文 EN | `Color.secondary` | 系统二级色，低调退后 |
| 中文（空闲） | `Color.primary` | 系统一级色，清晰可见 |
| 中文（输入中） | `Color.primary` | 同上 |
| 中文（倒计时） | 跟随弧色 | 琥珀→暗褐渐变 |

环轨：`Color.primary.opacity(0.08)` — 在亮/暗模式下都能隐约可见。

进度弧：保持琥珀色渐变设计不变（PRD §3.2），这是品牌识别色。

### 1.3 动画

与 PRD 一致：仅倒计时最后 5 秒做弧线 opacity 脉冲，尊重 reduceMotion。
